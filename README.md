# نبض‌شهر (NabzShahr)

پلتفرم **دوقلوی دیجیتال شهری** و **موتور شبیه‌سازی/تصمیم‌یار هوشمند** برای مدیران شهری —
پیش از اجرای هر تصمیم (بستن خیابان، پروژه عمرانی، سیاست شهری) اثر آن روی ترافیک، انرژی،
زیرساخت و رضایت شهروندان را از قبل ببینید.

این ریپو فعلاً **لندینگ‌پیج معرفی محصول** است (تک‌صفحه‌ای استاتیک)، نه پیاده‌سازی خود
پلتفرم دوقلوی دیجیتال.

## مسئله (#۰۹۳)

هیچ تصمیمی فقط روی یک بخش شهر اثر نمی‌گذارد. بستن یک خیابان الگوی ترافیک، زمان رسیدن
اورژانس، کسب‌وکارهای محلی، مصرف انرژی، کیفیت هوا و رضایت شهروندان را هم‌زمان تحت تاثیر
قرار می‌دهد؛ با این حال در بیشتر شهرها این تصمیم‌ها پیش از اجرا به‌صورت سیستماتیک
شبیه‌سازی نمی‌شوند.

## راه‌حل — دو لایه

1. **زیرساخت دوقلوی دیجیتال شهر** — یکپارچه‌سازی داده‌های GIS، ترافیک، حمل‌ونقل، آب و برق،
   پروژه‌های عمرانی و خدمات شهری در یک تصویر زنده از شهر.
2. **موتور هوش مصنوعی شبیه‌سازی و تصمیم‌یاری** — پیش‌بینی اثر سناریوهای مختلف پیش از اجرا
   (ترافیک، آب‌گرفتگی، تاب‌آوری زیرساخت و ...) بر اساس داده‌های زنده و تاریخی شهر.

## قابلیت‌ها

- شبیه‌سازی ترافیک پیش از اجرای تغییرات
- ارزیابی فشار پروژه‌های عمرانی بر خدمات شهری
- مدیریت بحران و تاب‌آوری (پیش‌بینی آب‌گرفتگی و ...)
- مدل‌سازی توسعه شهری و تراکم ساختمانی
- ارزیابی اثر سیاست‌های شهری پیش از تصویب
- موتور تصمیم‌یار هوشمند برای تخصیص بودجه و منابع

## مدل کسب‌وکار

فروش B2G به شهرداری‌ها، اشتراک سازمانی، پروژه‌های تخصصی شبیه‌سازی و خدمات تحلیلی.

## نقشه راه

شروع از یک مسئله مشخص (wedge) → یکپارچه‌سازی داده‌های شهر → افزودن موتور هوش مصنوعی →
دوقلوی دیجیتال کامل شهر.

## پشته فنی و اجرا

HTML/CSS/JS خالص، بدون framework یا build step. راست‌چین (RTL). فونت Vazirmatn به‌صورت
**لوکال** در `assets/fonts/` قرار دارد (پنج وزن woff2 + `OFL.txt`) و از هیچ CDN بیرونی
درخواستی ارسال نمی‌شود. برای پیش‌نمایش محلی:

```bash
python3 -m http.server
```

سپس آدرس نمایش‌داده‌شده را در مرورگر باز کنید.

> **توجه:** `script.js` به‌صورت ماژول ES بارگذاری می‌شود؛ باز کردن مستقیم
> `index.html` با `file://` در بیشتر مرورگرها ماژول را بلاک می‌کند (CORS). برای
> پیش‌نمایش همیشه از یک سرور استاتیک یا Docker استفاده کنید.

### قالب‌بندی فارسی

همه اعداد، درصدها و تاریخ‌های نمایش‌داده‌شده از `assets/js/format.js` عبور می‌کنند:
ارقام فارسی، جداکنندهٔ هزارگان `٬`، مبلغ تومانی، درصد با علامت، تاریخ شمسی
(`۱۴۰۵/۰۹/۰۲` یا `۲ آذر ۱۴۰۵`) و زمان نسبی (`۳ ساعت پیش`، `دیروز`). این ماژول هیچ
وابستگی بیرونی ندارد و تست‌های آن با `node --test tests/` اجرا می‌شوند.

### اجرا با Docker

روی سرور استقرار دارای Docker و افزونه Compose اجرا کنید:

```bash
docker compose up -d --build
```

سایت روی پورت `8080` سرور ارائه می‌شود. کانتینر Nginx با کاربر غیرریشه اجرا می‌شود،
health check دارد و فقط `index.html` و `assets/` را در image قرار می‌دهد.
فونت در image قرار دارد و صفحه بدون اینترنت هم فونت فارسی را نمایش می‌دهد؛ فرم تماس
و داشبوردها همان نمونه‌های نمایشی بدون backend هستند.

برای توقف:

```bash
docker compose down
```

### ساختار فایل‌ها

```
index.html            صفحه اصلی
assets/css/style.css  استایل‌ها
assets/js/script.js   منوی موبایل + فرم تماس
```

## آمادگی خرید

مدارک لازم برای فرآیند خرید سازمانی (پاسخ RFP، مشخصات فنی، نمونه توافق‌نامه داده،
کاتالوگ) و اعدادِ هنوز تعیین‌نشده در [`docs/procurement.md`](./docs/procurement.md)
نگهداری می‌شود.

## اتصال داده

قرارداد adapter و فهرست منابع داده‌ی شهری ایران (۱۳۷، GIS، ITS، BRT/AVL، تله‌متری،
گزارش‌دهی ملی) در [`docs/integrations.md`](./docs/integrations.md) است.
اعتبارسنجی نمونه:

```bash
node scripts/validate-adapter.mjs docs/adapter-example.json
```

## بک‌لاگ ایجنت‌ها

نُه کار مستقل و آماده اجرا برای شکاف‌های بازار ایران در
[`.github/issues/`](./.github/issues/README.md) نگهداری می‌شود؛ هر فایل شامل
دلیل، دامنه، معیارهای پذیرش قابل بررسی و فهرست فایل‌هاست.

برای ساخت واقعی این issues در گیت‌هاب (نیازمند `gh` احراز هویت‌شده):

```bash
./scripts/create-github-issues.sh
```

اسکریپت idempotent است و عنوان‌های موجود را رد می‌کند.

## پیش از انتشار

این پروژه یک دامنه‌ی **جایگزین** دارد که باید پیش از انتشار عمومی با دامنه‌ی واقعی
جایگزین شود: `https://nabzshahr.ir/`.

محل‌هایی که باید هم‌زمان تغییر کنند:

- `index.html` — `link rel="canonical"`، `og:url`، `og:image`، `twitter:image`
- `sitemap.xml` — مقدار `<loc>`
- `robots.txt` — خط `Sitemap:`
- JSON-LD — فیلدهای `url` و `logo` در بلوک‌های `Organization` و `WebSite`
- آی‌میل `info@nabzshahr.ir` در Owner سازمانی و فرم تماس، در صورت تغییر دامنه

> تا زمانی که این مقادیر واقعی نشوند، لینک‌های اشتراک‌گذاری و نقشه‌ی سایت به دامنه‌ای
> اشاره می‌کنند که ممکن است متعلق به این پروژه نباشد.
