# نبض‌شهر (NabzShahr)

پلتفرم **دوقلوی دیجیتال شهری** و **موتور شبیه‌سازی/تصمیم‌یار هوشمند** برای مدیران شهری —
پیش از اجرای هر تصمیم (بستن خیابان، پروژه عمرانی، سیاست شهری) اثر آن روی ترافیک، انرژی،
زیرساخت و رضایت شهروندان را از قبل ببینید.

این ریپو فعلاً **لندینگ‌پیج معرفی محصول** است (تک‌صفحه‌ای استاتیک)، نه پیاده‌سازی خود
پلتفرم دوقلوی دیجیتال.

## مسئله (#۰۹۳)

هیچ تصمیمی فقط روی یک بخش شهر اثر نمی‌گذارد. بستن یک خیابان الگوی ترافیک، زمان رسیدن
اورژانس، کسب‌وکارهای محلی، مصرف انرژی، کیفیت هوا و رضایت شهروندان را هم‌زمان تحت تاثیر
قرار می‌دهد؛ با این حال در بیشتر شهرها این تصمیم‌ها پیش از اجرا به‌صورت سیستماتیک
شبیه‌سازی نمی‌شوند.

## راه‌حل — دو لایه

1. **زیرساخت دوقلوی دیجیتال شهر** — یکپارچه‌سازی داده‌های GIS، ترافیک، حمل‌ونقل، آب و برق،
   پروژه‌های عمرانی و خدمات شهری در یک تصویر زنده از شهر.
2. **موتور هوش مصنوعی شبیه‌سازی و تصمیم‌یاری** — پیش‌بینی اثر سناریوهای مختلف پیش از اجرا
   (ترافیک، آب‌گرفتگی، تاب‌آوری زیرساخت و ...) بر اساس داده‌های زنده و تاریخی شهر.

## قابلیت‌ها

- شبیه‌سازی ترافیک پیش از اجرای تغییرات
- ارزیابی فشار پروژه‌های عمرانی بر خدمات شهری
- مدیریت بحران و تاب‌آوری (پیش‌بینی آب‌گرفتگی و ...)
- مدل‌سازی توسعه شهری و تراکم ساختمانی
- ارزیابی اثر سیاست‌های شهری پیش از تصویب
- موتور تصمیم‌یار هوشمند برای تخصیص بودجه و منابع

## مدل کسب‌وکار

فروش B2G به شهرداری‌ها، اشتراک سازمانی، پروژه‌های تخصصی شبیه‌سازی و خدمات تحلیلی.

## نقشه راه

شروع از یک مسئله مشخص (wedge) → یکپارچه‌سازی داده‌های شهر → افزودن موتور هوش مصنوعی →
دوقلوی دیجیتال کامل شهر.

## پشته فنی و اجرا

HTML/CSS/JS خالص، بدون framework یا build step. راست‌چین (RTL)، فونت Vazirmatn (Google
Fonts). برای پیش‌نمایش محلی:

```bash
python3 -m http.server
```

سپس آدرس نمایش‌داده‌شده را در مرورگر باز کنید.

### اجرا با Docker

روی سرور استقرار دارای Docker و افزونه Compose اجرا کنید:

```bash
docker compose up -d --build
```

سایت روی پورت `8080` سرور ارائه می‌شود. کانتینر Nginx با کاربر غیرریشه اجرا می‌شود،
health check دارد و فقط `index.html` و `assets/` را در image قرار می‌دهد.
فونت Google Fonts همچنان به اتصال اینترنت مرورگر نیاز دارد؛ فرم تماس و داشبوردها
همان نمونه‌های نمایشی بدون backend هستند.

برای توقف:

```bash
docker compose down
```

### ساختار فایل‌ها

```
index.html            صفحه اصلی
assets/css/style.css  استایل‌ها
assets/js/script.js   منوی موبایل + فرم تماس
```
